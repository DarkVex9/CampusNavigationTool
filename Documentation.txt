The map data is broken in "layers". Generally this is a floor of a building or the main outside layer, but it can be any chunk of map that needs its own image.

A layer consists of a string name, some metadata about it, and array of all nodes in it where a node's ID is its index.

Each node contains an integer ID, x position, y position, layer name, node type, and an array of all connections it has.
